# 2. Цели и не-цели

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [02-goals.md](02-goals.md), обе должны оставаться синхронными.

## Цели

- Быстрая локальная разработка: `npm install && npm run dev` — и приложение работает за 10 секунд.
- Контент — это **данные, а не код**: добавление урока не требует правки исходников.
- Полностью статическая сборка, деплой на GitHub Pages одним GitHub Actions workflow.
- Весь прогресс хранится локально (localStorage) с **экспортом/импортом** файла сохранения.
- Две последовательные таксономии, как в шведской системе: **SFI** (kurs A, B, C, D) и
  следом за ним **SVA grundläggande** (курс komvux, delkurs 1–4). Урок принадлежит
  ровно одному уровню. Полная лестница — в `CURRICULUM_ru.md`.
- Несколько режимов изучения темы, не только тесты.
- Типизированный и валидируемый контент: сломанный файл урока валит CI, а не браузер ученика.

## Не-цели (для v1)

- Нет сервера, аккаунтов, базы данных, мультиплеера.
- Нет платного TTS и хостинга аудиофайлов — используем Web Speech API браузера.
- Нет нативных мобильных приложений (достаточно PWA).
- Нет генерации контента ИИ в рантайме.
