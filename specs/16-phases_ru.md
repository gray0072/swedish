# 16. Этапы реализации

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [16-phases.md](16-phases.md), обе должны оставаться синхронными.

**Этап 1 — Каркас (день 1)**
Vite + React + TS + Tailwind + роутер + AppShell. Палитра и типографика из §11 закладываются
в `tailwind.config.ts` **сразу**, а не потом: натягивать визуальный стиль на готовые экраны
в разы дороже, чем начать с него. Шапка с тумблером `RU / EN`. Пустые страницы, зелёный
пайплайн деплоя, сайт живёт на GitHub Pages.

**Этап 2 — Пайплайн контента**
Zod-схемы, загрузчик `import.meta.glob`, реестр, скрипт валидации, 3 демо-урока A1.
Страницы треков, уровней и списка уроков рендерят реальный контент.

**Этап 3 — Страница урока**
Рендер теории, таблица слов, карточки слов, TTS.

**Этап 4 — Движок тестов**
ГПСЧ, выборка, генераторы, проверка ответов, UI раннера, типы `mc` / `type-answer` / `gap`,
экран результата. Юнит-тесты движка и проверки ответов.

**Этап 5 — Прогресс и награды**
Сторы Zustand, персист с миграциями, XP/монеты, серия дней, экспорт/импорт, страница статистики.

**Этап 6 — Остальные типы вопросов**
`order`, `match`, `listen`, `article`, `plural`, `verb-form`, `multi`, `true-false`.

**Этап 7 — Интервальные повторения**
Планировщик Лейтнера, страница `/review`, счётчик к повторению на главной.

**Этап 8 — Город**
Эпохи, здания, магазин, селекторы бонусов, карта города, достижения, праздничное сияние.
Карточки эпох с историческими опорами из §12.3.

**Этап 8b — Исторический слой**
Исторические карточки (`content/history/`), открытие зданиями, награда монетами, ключевые слова,
уходящие в колоду повторений. Тематические паки уроков из §12.5. Набор орнамента: лошадка-лоадер,
разделители-курбитс, печати младшего футарка, рамки эпох из змеиной ленты.

**Этап 9 — Масштабирование контента**
Добить SFI kurs A/B, наполнить kurs C/D, первые текстовые уроки для SVA grund delkurs 1.

**Этап 9b — Справочный раздел**
Обзорные статьи, сгенерированный банк слов и бытовые диалоги — за одним пунктом `/reference`
с тремя вкладками. Полный план в [REFERENCE_ru.md](REFERENCE_ru.md) и
[DIALOGUES_ru.md](DIALOGUES_ru.md).

**Этап 10 — Полировка**
PWA, офлайн, доперевод интерфейса, аудит доступности, Lighthouse ≥ 95.
