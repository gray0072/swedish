# 9. Маршруты (HashRouter)

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [09-routing.md](09-routing.md), обе должны оставаться синхронными.

| Путь | Страница |
|---|---|
| `/` | Главная: повторения на сегодня, серия, «продолжить обучение», сводка по городу |
| `/tracks` | Оба трека (SFI / SVA grundläggande) |
| `/tracks/:trackId/:levelId` | Список уроков уровня с кольцами прогресса |
| `/lesson/:levelId/:slug` | Теория + слова + «Пройти тест» |
| `/lesson/:levelId/:slug/quiz` | Прохождение теста |
| `/lesson/:levelId/:slug/result` | Результат + награды + следующий шаг |
| `/review` | Общая сессия интервальных повторений |
| `/city` | Карта Стокгольма, магазин, лента эпох |
| `/reference/summaries` и `/reference/summaries/:slug` | Обзорные статьи о языке |
| `/reference/words` | Банк слов — вся лексика приложения во всех формах |
| `/reference/dialogues` и `/reference/dialogues/:slug` | Бытовые диалоги |
| `/stats` | Графики: выучено слов, точность, тепловая карта активности |
| `/settings` | Язык, тема, TTS, экспорт/импорт, сброс |
