# 1. Концепция

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [01-vision.md](01-vision.md), обе должны оставаться синхронными.

**Статическое веб-приложение для изучения шведского**, размещённое на GitHub Pages, **без бэкенда**.

Основной цикл:

1. Ученик выбирает **тему** (урок) из трека уровня.
2. Урок показывает **короткую теорию** и/или **список слов**, с озвучкой.
3. Ученик нажимает **«Пройти тест»** → 10 вопросов из пула ~100.
4. За прохождение начисляются **XP** (мера обучения) и **монеты** (валюта для трат).
5. Монеты тратятся на **строительство Стокгольма**: от первобытного племени через эпоху
   викингов до современного города — и дальше, через четыре гипотетических будущих, которые
   прямо говорят, что они домысел (§12.8).
6. Здания дают **бонусы**, которые возвращаются в обучение (множители XP, больше повторений,
   тематические паки уроков) — цикл замыкается.

Главный принцип: **много разных способов учить шведский, каждый с позитивным подкреплением**.
Никаких наказаний. Нет жизней, нет провалов, прогресс не сгорает. Ошибка означает лишь то,
что вопрос вернётся в повторение раньше.
