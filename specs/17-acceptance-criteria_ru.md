# 17. Критерии приёмки v1

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [17-acceptance-criteria.md](17-acceptance-criteria.md), обе должны оставаться синхронными.

- [ ] `npm run dev` работает на чистом клоне без дополнительной настройки.
- [ ] Сайт открыт на GitHub Pages, все маршруты работают после жёсткой перезагрузки.
- [ ] Есть минимум 15 уроков, у каждого пул ≥ 100 фактических вопросов.
- [ ] В прогоне из 10 вопросов ни один вопрос не повторяется.
- [ ] Два подряд прогона одного урока не пересекаются по вопросам (если позволяет пул).
- [ ] XP, монеты, серия и состояние SRS переживают перезагрузку страницы и перезапуск браузера.
- [ ] Экспорт даёт JSON, который импорт полностью восстанавливает в другом браузере.
- [ ] Минимум 12 зданий первых трёх эпох доступны к покупке, бонусы работают.
- [ ] Бонусы заметно меняют числа наград на экране результата.
- [ ] Тест полностью проходится с клавиатуры (проверено вручную).
- [ ] Тумблер `RU / EN` в шапке мгновенно переключает интерфейс и все переводы, переживает
      перезагрузку, и ни на одном экране нет непереведённой строки ни в одном языке.
- [ ] Ни один урок не длиннее 5 минут; все серии из частей корректно сгруппированы в списке.
- [ ] Валидация контента ловит намеренно сломанный урок в CI (включая слишком длинный урок
      и отсутствующий перевод `en`).
- [ ] Юнит-тесты покрывают веса выборки, проверку ответов всех типов, формулы наград
      и планировщик повторений.
- [ ] В работе только палитра и шрифты из §11 — никаких случайных дефолтных цветов Tailwind,
      и каждый шрифт отрисовывает `å ä ö` и кириллицу.
- [ ] На экране теста нет орнамента; на экране города — есть.
- [ ] Есть минимум 10 исторических карточек, у каждой дата и заполненное поле `sources`.
- [ ] Слова из прочитанной исторической карточки всплывают в последующей сессии повторения.
- [ ] Ни одного рогатого шлема, ни одного старшего футарка, и рядом с 1252 годом не стоит
      слово «основан».
