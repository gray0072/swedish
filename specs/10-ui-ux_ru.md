# 10. Требования к UI/UX

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [10-ui-ux.md](10-ui-ux.md), обе должны оставаться синхронными.

- **Mobile-first.** Учатся в основном с телефона. Зоны нажатия в тестах ≥ 44 px.
- **Тёмная тема** через стратегию `class` в Tailwind, по умолчанию — системная.
- **Переключатель языка в шапке.** Тумблер `RU / EN` в верхней панели на каждой странице.
  Он меняет **и** язык интерфейса, **и** язык перевода рядом со шведским — настройка одна,
  а не две. По умолчанию `en`. Сохраняется в localStorage под ключом `swedish-app:language`
  (пишется сразу при переключении и дублируется в файл сейва) и читается до первой отрисовки,
  чтобы не мигал неправильный язык.
  Все строки через `i18n`, захардкоженного текста в компонентах нет. Шведский — только контент,
  шведской локали интерфейса в v1 нет.
- **Честность про уровни:** у каждого трека есть `note`, который рисуется над списком уровней:
  разбивка тем внутри курсов — прагматичное приближение, а не официальная программа
  Skolverket.
- **Озвучка везде:** у каждого шведского слова, примера и вопроса есть кнопка динамика.
  При первом запуске один раз предупредить, если голос `sv-SE` не установлен, со ссылкой на
  инструкции для ОС.
- **Позитивная обратная связь:** волна северного сияния за идеальный прогон, анимация счётчика
  монет, ненавязчивые звуки (отключаемые), подбадривающие фразы по-шведски. Полная спецификация
  движения, звука и тона — в §11.6–11.8.
- **Доступность:** полная навигация с клавиатуры, видимый фокус, `aria-live` для обратной
  связи, уважение `prefers-reduced-motion`, контраст ≥ 4.5:1.
- **PWA:** устанавливается, работает офлайн через service worker, кеширующий оболочку
  приложения и весь JSON контента.
