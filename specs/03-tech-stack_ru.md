# 3. Стек

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [03-tech-stack.md](03-tech-stack.md), обе должны оставаться синхронными.

| Задача | Выбор | Почему |
|---|---|---|
| Язык | **TypeScript** (strict) | Схемы контента и состояние геймификации сильно выигрывают от типов |
| Сборка | **Vite** | Мгновенный HMR, простой статический вывод, отличная поддержка GitHub Pages |
| UI | **React 18** | Самая большая экосистема, низкий порог входа |
| Роутинг | **React Router**, `HashRouter` | Хеш-роутинг работает на GitHub Pages без настройки сервера |
| Состояние | **Zustand** + `persist` | Минимум кода, персист в localStorage из коробки |
| Стили | **Tailwind CSS** | Быстрая итерация, консистентные отступы и цвета, тёмная тема сразу |
| Загрузка контента | `import.meta.glob` (eager) | Автообнаружение файлов уроков, нет ручного индекса |
| Валидация | **Zod** | Одни и те же схемы в CI и в дев-режиме рантайма |
| Markdown | `react-markdown` + `remark-gfm` | Теория пишется в Markdown |
| Тесты | **Vitest** + **@testing-library/react** | Общий конфиг с Vite, ноль настройки |
| Озвучка | **Web Speech API** (`speechSynthesis`, `sv-SE`) | Бесплатно, офлайн, без ассетов |
| Иконки | **lucide-react** | Единый стиль, tree-shaking |

> **Рассмотренная альтернатива:** SvelteKit или Astro со статическим адаптером. Оба отличные,
> но React + Vite даёт наименьшее трение и самую большую экосистему компонентов.
> Если проект станет резко контент-ориентированным, Astro будет лучше — вернуться к этому в v2.
