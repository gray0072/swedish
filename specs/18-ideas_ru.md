# 18. Дополнительные идеи (предложения сверх исходного задания)

> Часть технического задания — оглавление в [SPEC_ru.md](../SPEC_ru.md).
> Английская версия — [18-ideas.md](18-ideas.md), обе должны оставаться синхронными.

Всё это расширяет принцип «много способов учить с позитивным подкреплением».
Отсортировано по соотношению пользы к трудозатратам.

1. **Ежедневный вызов** — 5 смешанных вопросов из всего пройденного, одна попытка в день,
   щедрая награда монетами. Сильнейший механизм формирования привычки без сервера.
2. **Режим карточек** — колода на урок со свайпом/клавиатурой, без оценок, чистое повторение.
   Иногда человек не хочет, чтобы его проверяли.
3. **Слово дня** — карточка на главной с озвучкой и примером. Бесплатные монеты за прослушивание.
4. **Мастерская предложений** — из известных слов собирать предложения типом `order`; учит
   шведскому порядку слов (V2) — главной стене для начинающих.
5. **Диктант на слух** — TTS читает предложение, ученик его печатает. Очень полезно и
   бесплатно благодаря `speechSynthesis`.
6. **Тренировка произношения** — Web Speech API *recognition* (`sv-SE`) оценивает сказанное
   слово. Только Chrome, деградировать мягко. Очень «вау»-эффект.
7. **Музей ошибок** — страница личных повторяющихся ошибок («ты путаешь `en`/`ett` вот на этих
   12 существительных») с тренировкой в один тап. Превращает провалы в фичу.
8. **Тематические паки уроков от зданий** — постройка верфи «Васы» открывает урок про корабль
   «Васа» (реальные слова + культура). Делает город осмысленным, а не декоративным.
9. **Карточки шведской культуры** — fika, allemansrätten, midsommar, lagom, jantelagen.
   Открываются как награды за эпохи; коротко, приятно, запоминается.
10. **Тепловая карта активности** — сетка в стиле контрибуций GitHub на `/stats`.
    Дёшево и очень мотивирует.
11. **Витрина достижений** — бейджи отображаются на карте города как монументы.
12. **Карточка результата для шеринга** — рендер PNG через canvas за идеальный прогон.
    Бэкенд не нужен.
13. **Сезонные события** — Lucia (13 декабря), Midsommar, Kanelbullens dag (4 октября):
    временные уроки и украшения города. Дешёвый контент, большой возврат пользователей.
14. **Локальный рейтинг против себя прошлого** — «эта неделя против прошлой». Не требует сервера.
15. **Опциональная синхронизация (v2)** — GitHub Gist или Supabase, только по желанию,
    чтобы v1 оставался без бэкенда.

## Оставшиеся открытые вопросы

Все вопросы к запуску закрыты в разделе 0. Открытым остаётся только то, что касается v2:

- Свой домен через `CNAME` вместо подпути `/swedish/` — это изменит `base` в Vite.
- Стоит ли добавлять шведскую локаль интерфейса, когда приложение будет функционально готово.
- Стоит ли опциональная облачная синхронизация (идея 15) потери свойства «без бэкенда».
