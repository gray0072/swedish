A conditional sentence pairs an **om**-clause (if) with a main clause. When the **om**-clause comes first, Swedish often adds **så** (then) right before the main clause — optional, but common and natural.

```example
Om det regnar, så stannar vi hemma. — If it rains, then we'll stay home.
Om du är trött, så gå och lägg dig. — If you're tired, then go to bed.
```

The **så** simply marks where the main clause starts; without it the sentence is equally correct, just a touch less marked.

```example
Om jag hinner kommer jag på festen. — If I have time, I'll come to the party.
```

For an unreal condition, use the preterite or **vore** (the old subjunctive of *vara*) in the om-clause, and **skulle** in the main clause — this is the pattern from the previous lesson, now fully in place.

```example
Om jag vore du, skulle jag vänta till imorgon. — If I were you, I would wait until tomorrow.
```

Related words carry the same logic: **ifall** (in case) introduces a precaution, **i så fall** (in that case) picks up a condition already mentioned, and **annars** (otherwise) states what happens if the condition is NOT met.
