You already know that **att** ("that") introduces a subordinate clause, and
that inside such a clause a sentence adverb like inte moves before the finite
verb (the BIFF rule). Several other common conjunctions introduce subordinate
clauses the same way — they just carry different meanings.

**om** — "if" / "whether":

```example
Jag vet inte om han kommer. — I don't know if he is coming.
```

**när** — "when":

```example
Jag ringer när jag kommer hem. — I'll call when I get home.
```

**eftersom** — "because" / "since" (giving a reason):

```example
Vi stannade hemma eftersom det regnade. — We stayed home because it was raining.
```

**så att** — "so that" (expressing purpose or result):

```example
Hon talade tydligt så att alla förstod. — She spoke clearly so that everyone understood.
```

All four behave exactly like att for word order: the clause they introduce
keeps its own subject and verb, and if there is an inte inside it, inte comes
before the finite verb, not after.

```example
Jag stannar hemma eftersom jag inte mår bra. — I'm staying home because I don't feel well.
Hon frågade om jag inte ville komma. — She asked if I didn't want to come.
```

A quick way to spot a subordinate clause: it cannot stand alone as a full
sentence in the same way. "Eftersom det regnade" is not complete by itself —
it needs a main clause attached ("Vi stannade hemma, eftersom det regnade").
Contrast this with a main clause using "för" ("because", used more like
"since, you see"), which keeps main-clause word order and can start its own
sentence — a distinction covered in more detail later. For now, treat om, när,
eftersom, and så att as members of the same BIFF family as att.
