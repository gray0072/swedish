Шведский образует новые слова двумя очень продуктивными способами:
соединяя два слова вместе или добавляя суффикс.

**Сложные слова (compounds)** просто соединяют два существительных в одно
слово, с ударением на *первой* части.

```example
brev + låda → brevlåda — письмо + ящик → почтовый ящик
körkort + tillstånd → körkortstillstånd — права + разрешение → разрешение на обучение вождению
```

После соединения сложное слово ведёт себя как одно слово с одним родом
(обычно взятым от последней части) — никогда не пишите две части раздельно
или через дефис.

```example
Brevet ligger i brevlådan. — Письмо лежит в почтовом ящике.
```

Три суффикса превращают глагол или прилагательное в новое существительное, и
стоит уметь узнавать все три.

**-are** образует «деятеля» — человека, который делает то, что означает
глагол:

```example
arbeta → arbetare — работать → рабочий
läsa → läsare — читать → читатель
```

**-het** образует абстрактное существительное от прилагательного — само
качество:

```example
snäll → snällhet — добрый → доброта
fri → frihet — свободный → свобода
skön → skönhet — красивый → красота
```

**-ning** образует существительное действия/результата от глагола:

```example
undersöka → undersökning — обследовать → обследование
utbilda → utbildning — обучать → образование, обучение
```

Заметив эти модели, вы часто сможете угадать значение нового слова просто по
его корню и окончанию.
