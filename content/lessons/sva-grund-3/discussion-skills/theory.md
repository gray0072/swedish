A group discussion is different from a talk: several people speak in turn,
interrupt each other, and react to what others say. It needs its own set of
phrases, separate from "argumentative-text" and "short-talk-notes".

## Joining in

```example
Får jag lägga till något? — May I add something?
```

```example
Jag skulle vilja säga en sak. — I would like to say one thing.
```

## Objecting politely

```example
Jag ser det lite annorlunda. Jag tycker att... — I see it a bit differently. I think that...
```

```example
Det stämmer, men man skulle också kunna säga att... — That's true, but one could also say that...
```

## Agreeing

```example
Jag håller med om att det är ett viktigt problem. — I agree that this is an important problem.
```

## Summing up

At the end of a discussion, it helps to say the shared conclusion out loud:

```example
Om jag ska sammanfatta det vi kommit fram till, så... — If I'm to sum up what we've concluded, then...
```

## Rules for a good discussion

1. Let people finish their thought (`får jag avbryta?` — ask before
   interrupting, rather than cutting in silently).
2. React specifically to what was said instead of changing the subject.
3. Don't be afraid to disagree — `jag håller inte riktigt med om att...`
   sounds polite and to the point.
4. Someone sums up at the end so the group knows what it concluded.
