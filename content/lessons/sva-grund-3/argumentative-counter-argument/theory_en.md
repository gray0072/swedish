In "argumentative-text" you built a text using thesis — arguments — conclusion.
A stronger text goes one step further: it states the opponent's view
(**motargument**) and then refutes it (**bemötande**).

## Introducing the counter-argument

```example
Motståndare till detta hävdar att en kortare arbetsvecka skulle skada ekonomin. — Opponents of this claim that a shorter working week would harm the economy.
```

## Refuting it

Once you've stated the counter-argument, you need to refute or weaken it:

```example
Men det stämmer inte eftersom flera studier visar motsatsen. — But that's not true, because several studies show the opposite.
```

```example
Även om man kan invända att omställningen kostar pengar, väger fördelarna tyngre på lång sikt. — Even though one could object that the transition costs money, the advantages outweigh that in the long run.
```

## A softer formula

Sometimes it helps to partly agree first, then push back:

```example
Det är sant att en del företag skulle få högre kostnader, men de flesta skulle klara omställningen. — It's true that some companies would face higher costs, but most would manage the transition.
```

## The scheme with a counter-argument

1. Thesis.
2. Argument 1, argument 2.
3. **Counter-argument** (`motståndare till detta hävdar att...`).
4. **Refutation** (`men det stämmer inte eftersom...` / `även om man kan invända att...`).
5. Conclusion.

This kind of text reads as more honest: the writer shows they considered
another point of view instead of just ignoring it. `Dock` and `i själva verket`
help you glide smoothly from the objection back to your own position.
