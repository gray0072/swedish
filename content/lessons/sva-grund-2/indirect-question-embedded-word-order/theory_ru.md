Вопрос меняет форму, как только он встраивается внутрь другого предложения
— вопросительное слово остаётся, но порядок слов переключается с
вопросительного на порядок придаточного предложения.

## Прямой против косвенного

```example
Var bor du? — Где ты живёшь? (прямой: глагол сразу после var)
Jag undrar var du bor. — Интересно, где ты живёшь. (косвенный: подлежащее перед глаголом)
```

В прямом вопросе спрягаемый глагол идёт сразу после вопросительного слова.
Как только вопрос встраивается — после **undra**, **fråga**, **veta** и
подобных глаголов — подлежащее становится перед глаголом, как в любом
придаточном предложении.

```example
Vad heter hon? → Vet du vad hon heter? — Как её зовут? → Ты знаешь, как её зовут?
Vad var klockan? → Hon frågade vad klockan var. — Который был час? → Она спросила, который был час.
```

## Без вопросительного слова: используем om

Вопрос «да/нет» без вопросительного слова встраивается через союз **om**
(«ли»).

```example
Kommer han? → Jag vet inte om han kommer. — Он придёт? → Я не знаю, придёт ли он.
```

## Когда вопросительное слово — подлежащее: добавляем som

Если вопросительное слово само было бы подлежащим прямого вопроса (*Vem
ringde?*), встроенному предложению нужен **som** сразу после него — иначе у
предложения вовсе не будет подлежащего.

```example
Vem ringde? → Ingen vet vem som ringde. — Кто звонил? → Никто не знает, кто звонил.
Vad hände? → Polisen undersöker vad som hände. — Что случилось? → Полиция расследует, что случилось.
```

## Коротко

Встраивание вопроса сохраняет вопросительное слово (или добавляет **om**),
но всегда переключается на порядок придаточного предложения — подлежащее
перед глаголом — и вставляет **som**, когда вопросительное слово стоит на
месте подлежащего.
