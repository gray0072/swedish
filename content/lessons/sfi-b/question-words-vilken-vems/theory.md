You already know the basic question words (vad, var, när, hur, varför). Now
add a family built on **which**, plus **whose** and **how much/many**.

**vilken / vilket / vilka** — "which, what" — agrees with the noun just like
en/ett/plural does: **vilken** for en-words, **vilket** for ett-words,
**vilka** for plurals.

```example
Vilken bil är din? — Which car is yours? (en bil)
Vilket hus bor du i? — Which house do you live in? (ett hus)
Vilka bilar är dina? — Which cars are yours? (bilar, plural)
```

| noun type | question word | example |
|---|---|---|
| en-word | vilken | Vilken bok läser du? |
| ett-word | vilket | Vilket äpple vill du ha? |
| plural | vilka | Vilka böcker gillar du? |

**vems** — "whose" — is much simpler: it never changes, no matter the gender
or number of the noun that follows.

```example
Vems bok är det? — Whose book is that?
Vems jacka är det här? — Whose jacket is this?
Vems bilar är det? — Whose cars are those?
```

**hur mycket / hur många** — "how much / how many" — follows the same
mass-vs-count split you already learned with mycket/många:

```example
Hur mycket mjölk finns det? — How much milk is there?
Hur många bilar har ni? — How many cars do you have?
```

Putting them together in short exchanges:

```example
— Vilken bil är din? — Den röda. — Which car is yours? — The red one.
— Vems bok är det? — Det är min. — Whose book is that? — It's mine.
— Hur många barn har ni? — Två. — How many children do you have? — Two.
```

A quick way to remember: ask yourself what the answer would be. If the answer
needs "en/ett/plural" agreement (a specific one, from a set), use
vilken/vilket/vilka. If the answer is a person's name or "mine/his/hers", use
vems. If the answer is a number or quantity, use hur mycket/hur många —
matching mass or count nouns exactly as with mycket/många.
