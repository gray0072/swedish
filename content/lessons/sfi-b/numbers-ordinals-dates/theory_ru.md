Вы уже знаете числа 0-20. Дальше шведские числительные строятся из небольшого
набора «кубиков»: **tjugo** (20), **trettio** (30), **fyrtio** (40), **femtio**
(50), затем **hundra** (100) и **tusen** (1000). Составные числа пишутся и
произносятся одним словом, без «и».

```example
tjugoen — двадцать один
trettio — тридцать
hundra — сто
tvåhundra — двести
tusen — тысяча
```

Большие числа — это просто цепочка таких «кубиков»: **hundrafemtio** (150) —
буквально «сто-пятьдесят», а **tvåhundrasjuttio** (270) — «двести-семьдесят».

**Порядковые числительные** (первый, второй, третий...) — отдельный
небольшой список для заучивания. Большинство оканчиваются на **-e**, но первые
несколько — неправильные:

| количественное | порядковое |
|---|---|
| en/ett | första |
| två | andra |
| tre | tredje |
| fyra | fjärde |
| fem | femte |
| ... | ... |
| tio | tionde |

Порядковые числительные используются для этажей, позиций в списке — и для
**дат**. Дата всегда строится по формуле **den** + порядковое числительное +
название месяца:

```example
Idag är det den tredje maj. — Сегодня третье мая.
Vilket datum är det idag? — Какое сегодня число?
Mötet är den tionde juni. — Встреча десятого июня.
```

**Цены** в кронах используют обычное количественное числительное плюс слово
**kronor**:

```example
Vad kostar den? — Сколько это стоит?
Det kostar hundra kronor. — Это стоит сто крон.
Jackan kostar tvåhundra kronor. — Куртка стоит двести крон.
```

Полезный приём: чтобы спросить цену чего угодно, достаточно сказать **Vad
kostar...?** («Сколько стоит...?») — это работает и для кофе, и для
велосипеда.
