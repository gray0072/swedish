Вы уже знаете пять склонений множественного числа (-or, -ar, -er, -n, без
окончания). Теперь добавим ещё один слой: **определённое множественное число**
(«эти машины», а не просто «машины»). Правило строится прямо на неопределённом
множественном числе, которое у вас уже есть, — нужно просто добавить небольшое
окончание сверху.

| склонение | неопр. множественное | + окончание | опр. множественное |
|---|---|---|---|
| -or | flickor | **-na** | flickorna |
| -ar | bilar | **-na** | bilarna |
| -er | lägenheter | **-na** | lägenheterna |
| -n | äpplen | **-a** | äpplena |
| без окончания | hus | **-en** | husen |

```example
flickor — flickorna — девочки — эти девочки
bilar — bilarna — машины — эти машины
lägenheter — lägenheterna — квартиры — эти квартиры
äpplen — äpplena — яблоки — эти яблоки
hus — husen — дома — эти дома
```

Правило вкратце: большинство множественных форм, уже оканчивающихся на гласный
звук (-or, -ar, -er), просто добавляют **-na**. Склонение **-n**, которое уже
заканчивается на «-n», добавляет только **-a** (äpplen -> äpplena), а не повторяет
окончание. А формы множественного числа **без окончания** в неопределённой форме
(оканчивающиеся на согласный, как «hus» или «barn») добавляют **-en**.

```example
hundar — hundarna — собаки — эти собаки
barn — barnen — дети — эти дети
bord — borden — столы — эти столы
```

Итак, теперь у каждого существительного полная система из четырёх форм:
неопределённое единственное, определённое единственное, неопределённое
множественное, определённое множественное. Зная, к какому из пяти склонений
относится слово, вы можете вывести все четыре формы по одному и тому же
предсказуемому образцу — запоминать нужно только само склонение.
