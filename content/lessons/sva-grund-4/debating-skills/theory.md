A debate (en debatt) is different from a casual discussion: each side has a
clear position that must be stated, backed up, and defended against an
opponent. The tone is more formal than in "discussion-skills".

## Stating a position

```example
Jag intar ståndpunkten att skolan bör förbjuda mobiler i klassrummet. — I take the position that schools should ban phones in the classroom.
```

```example
Min utgångspunkt är att... — My starting point is that...
```

## Giving an argument

```example
Det starkaste argumentet för min sida är... — The strongest argument for my side is...
```

```example
Ett tungt vägande skäl är att... — A weighty reason is that...
```

## Answering an opponent

```example
Min motståndare hävdar att X, men jag menar att... — My opponent claims X, but I think that...
```

```example
Låt mig bemöta det argumentet. — Let me answer that argument.
```

```example
Det håller inte, av flera skäl. — That doesn't hold up, for several reasons.
```

## Concluding

```example
Sammanfattningsvis vidhåller jag min ståndpunkt. — In conclusion, I stand by my position.
```

## Rules for a formal debate

1. State your position at the start — `jag intar ståndpunkten att...`
2. Back up every argument with a reason: `ett skäl är att...`
3. Answer the opponent's actual argument (`bemöta`), not a different topic.
4. Attack the argument, not the person.
5. Sum up your position clearly at the end.
