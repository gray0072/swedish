# Группы глаголов 1–4

Шведские глаголы делятся на четыре группы по тому, как они образуют претерит и супин (форму,
нужную для сложных времён). В настоящем времени разница почти не видна — почти каждый глагол
просто добавляет **-r** (всю систему см. в `verb-forms`).

| Группа | Инфинитив | Презенс | Претерит | Супин | Пример |
|---|---|---|---|---|---|
| **1** | -a | -ar | -ade | -at | tala → talar → talade → talat (говорить) |
| **2** | -a / согласный | -er | -de / -te | -t | ringa → ringer → ringde → ringt (звонить) |
| **3** | гласный (не -a) | -r | -dde | -tt | bo → bor → bodde → bott (жить) |
| **4** (сильные) | -a | -er | смена гласного | -it | skriva → skriver → skrev → skrivit (писать) |

## Группа 1 — самая большая и самая предсказуемая

Если инфинитив глагола заканчивается на **-a** и глагол не входит в число исключений, он почти
наверняка относится к группе 1. Это ещё и продуктивная группа: новые заимствования (**maila**,
«отправлять по имейлу») автоматически спрягаются по этой модели.

```example
arbeta — arbetar — arbetade — arbetat (работать)
studera — studerar — studerade — studerat (учиться)
```

## Группа 2 — раскалывается правилом написания

Группа 2 делится на 2a и 2b в зависимости от того, чем заканчивается основа: после звонкого
согласного (в большинстве случаев) претерит заканчивается на **-de**; после глухого
согласного (`k, p, s, t, x`) — на **-te** вместо этого; написание следует за произношением.

```example
ringa — ringer — ringde — ringt (звонить, звонкая основа)
läsa — läser — läste — läst (читать, глухая основа)
```

## Группа 3 — короткая и с гласным на конце

Глаголы, чей инфинитив уже заканчивается на ударный гласный, отличный от **-a** (bo, tro, sy,
må), удваивают конечный согласный окончания вместо добавления нового.

```example
tro — tror — trodde — trott (верить)
```

## Группа 4 — «неправильные» глаголы

Группа 4 — это сильные глаголы, у которых претерит образуется **изменением корневого
гласного** вместо добавления окончания — примерно как английские неправильные глаголы (write →
wrote) или собственные корневые чередования русского языка. Их нельзя вывести по правилу,
только выучить — но `strong-verbs` группирует их по гласному образцу, что делает сотню таких
глаголов гораздо легче запомнить, чем плоский список.

```example
äta — äter — åt — ätit (есть)
dricka — dricker — drack — druckit (пить)
```

## Настоящие исключения

Несколько самых частых глаголов языка не относятся чисто ни к одной группе: **vara** («быть»)
→ är, var, varit; **vilja** («хотеть») → vill, ville, velat; **kunna** («мочь, уметь») → kan,
kunde, kunnat. Выучите их первыми и отдельно от остальных.
