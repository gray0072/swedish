# Conjunctions and connectors

Swedish, like `parts-of-speech` explains, splits "conjunction" into two grammatically distinct
classes — and which one a word belongs to changes the whole sentence's word order.

## Coordinating conjunctions (konjunktion) — no reordering

These join two main clauses without disturbing either one's own V2 order:

```example
Jag är trött, men jag jobbar vidare. — I'm tired, but I'm carrying on working.
Hon läser, och han lagar mat. — She's reading, and he's cooking.
```

The core set: **och** (and), **men** (but), **eller** (or), **för** (because/for — note: not
"for" as in duration), **så** (so).

## Subordinating conjunctions (subjunktion) — triggers BIFF

These open a subordinate clause, which cannot stand alone and which reorders its own sentence
adverbs — `inte` moves *before* the finite verb instead of after it (the BIFF rule, in
`word-order`):

```example
Jag stannar hemma eftersom jag är sjuk. — I'm staying home because I'm sick.
Jag vet att han inte kommer. — I know that he isn't coming. (inte before "kommer")
```

The core set: **att** (that), **om** (if/whether), **när** (when), **eftersom**/**för att**
(because), **innan** (before), **efter att** (after), **fastän**/**trots att** (although — see
`concessive-clauses`), **om** in its conditional sense (see `conditional-om-sa`).

## Causal and concessive clauses

`causal-clauses` drills **eftersom**, **för att**, **därför att** — all roughly "because", with
subtle differences in formality and in which clause the reason attaches to. `concessive-clauses`
drills **fastän**, **trots att**, **även om** — all roughly "although", used to concede a point
before contradicting it:

```example
Fastän det regnade gick vi ut. — Although it was raining, we went out.
```

## Text connectors — holding a written text together

Beyond single-clause conjunctions, Swedish writing leans on a set of adverbial connectors to
link whole sentences: **dessutom** (moreover), **däremot** (on the other hand), **därför**
(therefore), **å ena sidan … å andra sidan** (on the one hand … on the other hand). These
behave as ordinary sentence adverbs for word-order purposes — they take first position and
trigger the subject-verb swap from `word-order` just like any other fronted element:

```example
Det regnade. Dessutom var det kallt. — It was raining. Moreover, it was cold.
```

`text-connectors` drills the full set used in the SVA grund writing lessons, and
`och-men-conjunctions` covers the basic coordinating set in more depth.
