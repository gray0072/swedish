# Группы глаголов 1–4

Шведские глаголы делятся на четыре группы по тому, как они образуют прошедшее время и
супин (форму, нужную для сложных времён). В настоящем времени разница почти не
чувствуется — почти все глаголы просто добавляют **-r** (подробнее в теме «Настоящее время
глаголов»).

| Группа | Инфинитив | Наст. время | Прош. время | Супин | Пример |
|---|---|---|---|---|---|
| **1** | -a | -ar | -ade | -at | tala → talar → talade → talat (говорить) |
| **2** | -a / согласная | -er | -de / -te | -t | ringa → ringer → ringde → ringt (звонить) |
| **3** | гласная (кроме -a) | -r | -dde | -tt | bo → bor → bodde → bott (жить) |
| **4** (сильные) | -a | -er | смена гласной | -it | skriva → skriver → skrev → skrivit (писать) |

## Группа 1 — самая большая и самая предсказуемая

Если глагол в инфинитиве оканчивается на **-a** и не входит в исключения — почти наверняка
это группа 1. Она же самая продуктивная: новые заимствованные глаголы (**maila**,
«отправить письмо по имейлу») автоматически спрягаются по этой модели.

```example
arbeta — arbetar — arbetade — arbetat (работать)
studera — studerar — studerade — studerat (учиться)
```

## Группа 4 — «неправильные» глаголы

Группа 4 — это сильные глаголы, где прошедшее время образуется сменой корневой гласной,
без окончания **-de/-te** — почти как английские irregular verbs (write → wrote) или
русские чередования в корне. Их не вывести по правилу, только запомнить:

```example
äta — äter — åt — ätit (есть, кушать)
dricka — dricker — drack — druckit (пить)
```

## Настоящие исключения

Несколько важнейших глаголов не входят ни в одну группу чисто: **vara** («быть») → är,
var, varit; **vilja** («хотеть») → vill, ville, velat; **kunna** («мочь/уметь») → kan,
kunde, kunnat. Это самые частотные глаголы языка — их стоит выучить первыми и отдельно.
