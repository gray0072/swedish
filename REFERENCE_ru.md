# Справочник — обзорные статьи, банк слов и диалоги

Это программный документ, как [CURRICULUM_ru.md](CURRICULUM_ru.md), но для той половины
приложения, которая **не является курсом**. CURRICULUM_ru.md перечисляет 400 уроков: каждый
учит одному пункту, на одном уровне, за пять минут. Это правильная форма для обучения и
неправильная форма для того, чтобы *что-то посмотреть*. Этот файл описывает справочный
раздел, который отвечает на вопросы, недоступные лестнице уроков, и существует для того,
чтобы новая сессия могла открыть его и начать писать контент, не восстанавливая контекст.

Каталог диалогов достаточно велик, чтобы жить отдельно: см. [DIALOGUES_ru.md](DIALOGUES_ru.md).
Английский оригинал этого файла — [REFERENCE.md](REFERENCE.md), и обе версии должны
оставаться синхронными ([AGENTS.md](AGENTS.md)).

## 1. Что это заменяет

В `content/grammar/` лежат три статьи — порядок слов, en/ett, группы глаголов 1–4 —
написанные только по-русски, что [AGENTS.md](AGENTS.md) называет багом. Их не удаляют: они
зерно гораздо большего раздела, переписанного по-английски с переводом `_ru` рядом, а папка
переименовывается в `content/reference/`, потому что раздел — уже не только грамматика.

Статья о группах глаголов — образец для всего набора: один экран, одна таблица, показывающая
систему целиком, примеры, которые ученик может произнести вслух, и завершающий абзац о
настоящих исключениях. Каждая статья ниже написана по этой форме.

## 2. Три поверхности, один раздел

| Поверхность | Отвечает на | Источник | Пишется вручную? |
|---|---|---|---|
| **Обзорные статьи** | «Как это устроено в целом?» | `content/reference/*.md` | Да — 20 статей, §4 |
| **Банк слов** | «Какая у этого слова форма?» | все `vocab.json`, агрегированные | **Нет — генерируется**, §5 |
| **Диалоги** | «Как это звучит между людьми?» | `content/dialogues/*.json` | Да — 30 сцен, [DIALOGUES_ru.md](DIALOGUES_ru.md) |

## 3. Правила для всего раздела

1. **Здесь ничего не оценивается.** Нет XP, нет проходного балла, нет замков, нет колец
   прогресса, нет предусловий. Библиотека, которая тебя оценивает, — это тест. Единственный
   мост к обучающему циклу — мост SRS (§5.4 и `keyPhrases` в DIALOGUES_ru.md §3): он добавляет
   элементы в колоду повторения, не добавляя вердикта.
2. **Обзорные статьи обобщают; уроки учат.** Статья, которая начала тренировать, должна была
   быть уроком. Урок, который начал систематизировать всю глагольную систему сразу по восьми
   уровням, должен вместо этого ссылаться на статью.
3. **Ничего не дублируется, всё связано перекрёстными ссылками** (§6.4). Факт живёт в одном
   месте, а из остальных на него указывают.
4. **Английский канонический.** `<slug>.md` — английский; `<slug>_ru.md` — перевод, который
   выбирается языковым тумблером в шапке ровно так же, как уже работают `theory.md` /
   `theory_ru.md`.
5. **Одна запись в навигации.** У раздела есть глубина; у обвязки интерфейса — нет (§6).

## 4. Обзорные статьи — `content/reference/`

### 4.1 Формат файлов

```
content/reference/
├─ index.json              # slug → group + order. Без заголовков: они берутся из заголовков статей
├─ verb-groups.md          # английский, начинается с единственного заголовка "# Title"
├─ verb-groups_ru.md       # русский перевод той же статьи
└─ …
```

```jsonc
// content/reference/index.json
{
  "articles": [
    { "slug": "how-swedish-works", "group": "overview", "order": 10 },
    { "slug": "verb-groups",       "group": "verbs",    "order": 20 }
  ]
}
```

Загрузчик уже выводит слаг из имени файла, а заголовок — из заголовка `# `; `index.json`
добавляет только группировку и порядок, так что статья никогда не описывается дважды. Файл
без записи в индексе или запись без файла — ошибка валидации.

### 4.2 Объём и форма

Длиннее, чем теория урока, и всё ещё на один присест: **400–900 слов**, минимум одна таблица,
блоки `example` для всего, что предназначено произноситься вслух, и завершающий абзац об
исключениях — о том, на чём новичок реально спотыкается. Статья может охватывать сразу все
уровни программы; в этом её смысл.

### 4.3 Двадцать статей

`[x]` — написана, на обоих языках. `[ ]` — не начата. Строка `→` называет уроки программы,
которые статья систематизирует, чтобы перекрёстные ссылки §6.4 можно было развести прямо по
ходу написания.

**Группа `overview` — как устроен язык**

- [x] 1. `how-swedish-works` — ориентирующая статья, написанная для того, кто приходит из
  русского или английского: нет падежей, два рода, определённый артикль приклеен к концу
  слова, глаголы никогда не меняются по лицам, и V2. Что легче, чем ожидалось, и где
  настоящая стена.
- [x] 2. `parts-of-speech` — substantiv, verb, adjektiv, adverb, pronomen, preposition,
  konjunktion, räkneord, interjektion: шведский метаязык в одной таблице, потому что SVA
  grundläggande учит *на нём*. → уроки грамматики SVA grund
- [x] 3. `sentence-types` — утверждение, вопрос (с v-словом и да/нет), придаточное
  предложение, повелительное наклонение и что меняется в каждом из них. →
  `statement-word-order`, `simple-questions`, `wh-questions`
- [x] 4. `word-order` — **переписанная существующая статья.** V2, fundament, инверсия, правило
  BIFF и где стоит `inte` в главном предложении против придаточного, разложенное как
  satsschema. → `statement-word-order`, `negation-inte`, уроки SVA о придаточных
- [x] 5. `pronunciation-and-spelling` — долгота гласного как смыслоразличительный признак,
  звуки sj- и tj-, мелодика предложения и буквы, которые читаются не так, как ожидает русский
  или английский читатель. → `vowel-length`, `letter-sound-correspondence`,
  `word-stress-melody`, `connected-speech-reductions`

**Группа `verbs` — глагольная система**

- [x] 6. `verb-groups` — **переписанная существующая статья** (переведённая на английский,
  русская оставлена как `_ru`). Группы 1–4, таблица, продуктивная группа, сильные глаголы и
  настоящие исключения. → `present-tense-basics`, `imperative-four-groups`
- [x] 7. `verb-forms` — все формы, какие есть у одного шведского глагола, в одном месте:
  infinitiv, presens, preteritum, supinum, perfekt и pluskvamperfekt, imperativ, presens- и
  perfektparticip, а также пассив (`-s`, `bli`, `vara`). → `tense-system-overview`,
  `s-passive-bli-passive`, `pluperfect-narrative`
- [x] 8. `tense-system` — *какое* время выбрать и почему: ловушка perfekt против preteritum и
  то, как шведский говорит о будущем через presens, `ska` и `kommer att`.
  → `tense-system-overview`
- [x] 9. `modal-verbs` — `ska`, `vill`, `kan`, `måste`, `får`, `bör`, `brukar`, `skulle`,
  каждый с идущим за ним голым инфинитивом, и та вежливость, которую покупает `skulle`.
  → `skulle-infinitive-politeness`, `infinitive-constructions`
- [x] 10. `strong-verbs` — глаголы четвёртой группы, выстроенные **по модели гласных**
  (`i–e–i`: skriva/skrev/skrivit; `ju–ö–u`: bjuda/bjöd/bjudit; …), — именно это делает сотню
  неправильных глаголов запоминаемой, а не плоским списком. Ссылается в банк слов с
  фильтром по четвёртой группе.

**Группа `nouns` — система существительного**

- [x] 11. `noun-genders` — **переписанная существующая статья.** en/ett: что на самом деле
  предсказывает род (окончания, смысловые группы), почему его приходится учить вместе со
  словом и чего стоит ошибка. → `en-ett-basics`
- [x] 12. `noun-forms` — четыре формы и пять склонений множественного числа (`-or`, `-ar`,
  `-er`, `-n`, нулевое), неправильные множественные, генитив на `-s` и составные слова, где
  шведский строит одно длинное слово из трёх. → `definite-form-basics`,
  `plural-recognition`, `genitive-longer-phrase`

**Группа `words` — прилагательные, наречия и маленькие слова**

- [x] 13. `adjective-forms` — согласование в трёх формах (`en stor bil`, `ett stort hus`,
  `stora hus`), определённая форма после `den/det/de` и исключения, которые стоит выучить:
  `liten/litet/lilla/små`, `gammal/gammalt/gamla`. → `liten-agreement`
- [x] 14. `comparison` — komparativ и superlativ: `-are/-ast`, `mer/mest`, а также
  `bra/bättre/bäst`, `dålig/sämre/sämst`, `många/fler/flest`.
- [x] 15. `adverbs` — образуются от прилагательных через `-t`, где они стоят в предложении, и
  наречия места, которые ходят парами (`hem/hemma`, `dit/där`, `ut/ute`), — различение,
  которого ни русский, ни английский так не отмечают.
- [x] 16. `pronouns` — личные, объектные, притяжательные, **возвратные** (`sin` против `hans`,
  классическая ошибка), указательные, относительное `som` и безличное `man`.
  → `personal-pronouns`, `min-mitt`, `det-har-dar`, `relative-clauses`, `impersonal-det`
- [x] 17. `prepositions` — `i`/`på`/`till`/`hos`/`vid`, выражения времени и пары глагол +
  предлог, которые приходится учить целиком (`tycka om`, `titta på`, `vänta på`).
  → `prepositions-i-pa`, `pa-with-days`, `abstract-prepositions`, `verb-preposition-pairs`
- [x] 18. `numbers-time-dates` — räkneord, порядковые, часы (включая `halv nio` = 8:30), даты,
  деньги и телефонные номера. → `numbers-0-20`, `clock`, `writing-dates`, `phone-numbers`
- [x] 19. `conjunctions-and-connectors` — сочинительные (`och`, `men`, `för`, `så`) против
  подчинительных (`att`, `om`, `när`, `eftersom`, `fastän`) и то, что вторые делают с порядком
  слов; затем связки, которые держат письменный текст вместе.
  → `och-men-conjunctions`, `causal-clauses`, `concessive-clauses`, `text-connectors`
- [x] 20. `word-formation` — составные слова, приставки `o-` и `miss-`, суффиксы `-are`,
  `-het`, `-ning` и то, как впитываются заимствования (`maila`, `deadline`). Статья, которая
  позволяет ученику угадать слово, которого он никогда не видел. → `word-formation-o-miss`

## 5. Банк слов — генерируется, а не пишется вручную

«Большой список глаголов во всех формах, большой список существительных во всех формах» не
требует нового контента: **контент уже есть**, он разбросан по 400 файлам `vocab.json`, и
валидация уже требует, чтобы у каждого существительного были род и все четыре формы, а у
каждого глагола — группа и все четыре основные формы (SPEC_ru.md §15). Банк слов — это
**представление над существующим словарём**, а не второй список, который надо поддерживать, —
и только поэтому список такого размера может оставаться корректным.

`adjFormsSchema` (§5.3) добавлена, и дозаполнение почти завершено — флот агентов прошёл по
всем 400 папкам уроков; у двух из них истекло окно лимита запросов перед самым концом, так
что небольшой остаток всё ещё открыт:

|---|---|---|---|
| noun | 2 347 | 210 | — |
| phrase | 1 027 | — | — |
| verb | 986 | 21 без форм, 102 без группы | — |

`hela`, `samma`). Реальный остаток работы меньше, чем говорят голые цифры, но он есть.

### 5.2 Таблицы

По одной таблице на часть речи — тот же элемент, увиденный вширь:

| Представление | Колонки |
|---|---|
| Глаголы | infinitiv · presens · preteritum · supinum · imperativ · группа · перевод · урок |
| Существительные | en/ett · obestämd sg · bestämd sg · obestämd pl · bestämd pl · перевод · урок |
| Прилагательные | positiv (en / ett / множественное) · komparativ · superlativ · перевод · урок |
| Всё остальное | слово · часть речи · перевод · пример · урок |

Строки дедуплицируются по шведскому слову; слово, которому учат несколько уроков, оставляет
одну строку и ссылается на них все. В каждой строке есть кнопка озвучки, как у любой другой
шведской строки в приложении.

### 5.3 Работа по схеме — сделана, с одним осознанным отступлением от исходного плана

- **Сделано.** `adjFormsSchema` — `{ positive, neuter, plural, comparative, superlative }` —
  уже в `src/content/schema.ts`, добавлена в объединение `forms`.
- **Осознанно не сделана обязательной.** Исходный план говорил сделать `forms` обязательным
  для каждого существительного/глагола/прилагательного и заставить
  `scripts/validate-content.ts` падать на отсутствующей форме. Реальное дозаполнение показало,
  почему это было бы неправильно: у некоторых существительных форм честно не может быть —
  слова только во множественном числе (`pengar`, `sopor`), имена собственные и названия
  ведомств (`Skatteverket`, `CSN`, `Anna`), полностью неизменяемые прилагательные (`gratis`,
  `hela`, `samma`). Обязательное поле заставило бы придумывать данные именно для этих слов.
  `forms` остаётся опциональным; полноту стоит проверять глазами, а не заставлять схему лгать
  о настоящем шведском.
- Дозаполнение существительных/глаголов/глагольных групп/прилагательных выше почти завершено
  (таблица в §5.1 показывает остаток) — флот параллельных агентов прошёл по всем 400 папкам
  уроков.
- Научить `scripts/content-stats.ts` печатать таблицу из §5.1 — всё ещё открыто, небольшая
  отдельная задача.

### 5.4 Фильтры, а не страницы

Строка поиска, ряд вкладок по частям речи и три переключателя, читающие состояние SRS,
которое приложение и так хранит: **все слова** / **слова, которые я видел** / **слова к
повторению**. Последний превращает банк слов в инструмент учёбы, не изобретая ни одной
новой механики, — это та же колода повторения, отсортированная как словарь. Список
виртуализирован; 3 528 строк не должны стоить ни секунды прокрутки.

## 6. Организация интерфейса — как его не перегрузить

Этот раздел примерно утраивает объём материала в приложении. Вся дизайнерская задача — в том,
чтобы *интерфейс* остался прежнего размера.

### 6.1 Одна запись в навигации

Пункт `Grammar`, который есть только на десктопе, становится **`Reference`**, и больше ничего
не добавляется. Нижняя панель на мобильном сохраняет свои пять основных направлений
нетронутыми: справочный раздел — это место, куда идут намеренно, а не часть ежедневного цикла.

### 6.2 Хаб из трёх вкладок, каждая — настоящий маршрут

| Путь | Страница |
|---|---|
| `/reference` | Хаб; редиректит на `/reference/summaries` |
| `/reference/summaries` | 20 статей, сгруппированных как в §4.3 |
| `/reference/summaries/:slug` | Одна статья |
| `/reference/words` | Банк слов — построен, сгруппирован по части речи и частотной полосе (§5.4) |
| `/reference/dialogues` | 30 сцен, сгруппированных по ситуациям — заглушка, пока не написан DIALOGUES_ru.md |
| `/reference/dialogues/:slug` | Один диалог |

Вкладки — это маршруты, а не состояние компонента, поэтому корректно ведут себя и кнопка
«назад», и отправленная кому-то ссылка. Старые пути `/grammar` удаляются, а не становятся
алиасами: сайт статический, ломать некого, а редирект, который никому не нужен, — прокладка,
живущая дольше своей причины.

### 6.3 Правила, которые держат каждую вкладку лёгкой

- **Группы по умолчанию свёрнуты**, кроме первой. Каждая вкладка открывается пятью-шестью
  заголовками на телефоне, а не стеной из сорока ссылок.
- **Никаких колец прогресса, процентов и бейджей** нигде в разделе (§3.1). Визуальная тишина
  *и есть* сигнал того, что это не курс.
- **Один экран — одна задача.** Страница статьи — это текст, банк слов — таблица,
  диалог — расшифровка. Ничто не встроено ни во что другое.
- Таблица банка слов — единственный элемент в приложении, прокручиваемый по горизонтали,
  и она внутри собственного контейнера, по мобильным правилам SPEC_ru.md §10.

### 6.4 Перекрёстные ссылки вместо дублирования

- **Сделано.** Урок с `"kind": "grammar"` показывает под своей теорией одну ссылку —
  *«Посмотреть систему целиком →»* — на статью, которая его покрывает. Это главный путь
  обнаружения раздела: ученик встречает его ровно тогда, когда он ему нужен. Соответствие
  живёт в `src/content/referenceLinks.ts`, перенесённое из пометок `→` в §4.3.
- **Сделано.** Статья заканчивается уроками, которые её отрабатывают, взятыми из тех же
  пометок `→` — разрешёнными по всем уровням, где точка повторяется (`getLessonsBySlug`),
  ведь грамматика намеренно повторяется (CURRICULUM_ru.md).
- **Сделано.** Строка банка слов ссылается на урок, который учит этому слову.
- **Не сделано.** Ссылка диалога на статью по грамматике, на которую он опирается — зависит
  от DIALOGUES_ru.md, который не написан.

### 6.5 Что намеренно *не* добавляется

Никакой справочной карточки на главном экране, никакой «статьи дня», никакого поиска по всему
приложению. Главный экран принадлежит ежедневному циклу — повторения к сроку, серия,
продолжить обучение, город, — и прикрутить к нему библиотеку означало бы заплатить ровно тем,
что этот раздел пытается уберечь.
